# 如何审阅测试证据

| 类别 | 真实输入 | 核心断言 | 不证明什么 |
|---|---|---|---|
| Harness / FakeModel | 预写 ToolCall、临时文本、小图 | 工具返回模型、失败不丢用量、串并行边界、权限、上下文压缩与会话恢复 | 不证明真实模型会自主选对工具 |
| 结构化工具程序测试 | 自制 PDF/PNG/Manifest/HTML | 参数合同、来源/版本核验、结果持久化、错误可读 | 不证明论文解析准确或页面美观 |
| 页面闭环恢复 | 临时页与故障注入；多数浏览器调用被替换为桩 | 保存后渲染失败可恢复、重复调用幂等、旧审核失效、未审核禁止导出 | 桩截图不是真实渲染 |
| 独立审核合同 | 预写 JSON 结论、证据缺口/错误/视觉偏好 | 关键错误不被 pass 隐藏，证据不足不冒充已证实事实错误，独立维度不能互相替代 | 不证明真实审核误报率下降 |
| 本地浏览器导出 | 自制红色 PNG + HTML | 实际 Chromium/PptxGenJS 输出背景/文本/独立图片，cover 裁剪被拒绝 | 低层夹具无正式审批，不能算正式交付 |
| Demo C | 脚本 HTML + FakeModel | 两版真实截图、Session 恢复、版本冲突与导出拒绝 | 无真实模型质量判断，也无 PPTX 交付 |
| Demo B 预检 | 正式工具和 Skills 配置 | 可装配、路径可解析、依赖存在；不发送模型请求 | 不证明 Key 有效、ID 可用或真实任务通过 |
| 静态展示 | 脱敏历史封面及 numeric 摘录 | 文件可访问、资源完整、版本标签正确 | 不可复现全部私有历史，也不是此次运行 |

`agent_harness/tests` 和选定领域测试复制自原项目；只移除依赖未发布历史资产的一项可选测试，没有把历史 skip 计为通过。`tests/test_release.py` 验证新发布结构、fixture 来源、真实 Demo 预检无网络和页面门禁。

所有测试默认无需供应商 Key。不因环境中存在 Key 就调用模型；浏览器测试会启动本地浏览器。CI 仅运行这些离线范围。真实 Demo 必须显式 `--run`，本轮未执行。

查看 `reports/verification.md` 获取准确次数、失败及修复过程。完整本机日志在 `reports/local-*` 或 `.build`，默认不进入发布包，避免公开机器路径。
