# HTML 到可编辑 PPTX 的当前约束

## 页面与元素标记

- 页面按 ThemeSpec 的像素尺寸制作，首版默认 1600 × 900。
- 需要导出的元素必须有唯一 `id`，并优先标记：
  - `data-pptx="text"`：可编辑文本。
  - `data-pptx="image"`：独立图片；元素本身或内部应有一个 `<img>`。
  - `data-pptx="shape"`：简单形状，可用 `data-shape="rect|ellipse|line"`。
- 元素位置以浏览器实际 `getBoundingClientRect()` 为准；不要依赖不可见占位或伪元素承载关键内容。
- 绑定中的 `element_id` 必须在 HTML 中存在，并与资产/证据引用对应。

## 当前可靠支持

- 纯色页面背景。
- 中文和英文文本、字号、字重、斜体、颜色、左/中/右对齐。
- PNG/JPEG 等栅格图像，作为独立对象导出。
- 简单纯色矩形与边线；圆角、虚线等装饰可近似为方角、实线，不依赖它们表达事实。
- 导出保留浏览器实际文字行及行内样式；文字仍为独立可编辑对象，不以整页截图代替。

## 会降级或不保证一致

- 当前导出明确拒绝 CSS background-image/渐变、CSS transform；不要指导模型依赖这些效果后再等待降级。
- 滤镜、混合模式、复杂阴影、伪元素等不保证一致，关键文字和科学内容不用这些方式承载。
- canvas、视频、动画与复杂 SVG。
- `object-fit: cover` 和祖先容器对科学图像的裁剪当前被拒绝。用完整栅格原图、`object-fit: contain`，
  按真实宽高比分配空间。需要局部展示时先选择经溯源的局部资产，不通过CSS裁掉关键图块。
- 跨机器字体替换和字符度量仍可能影响细节；以实际 PowerPoint 渲染为准。

不要把关键论文图表做成 CSS 背景或整页截图。已拒绝的特性需要先替换为支持的实现，
标记为装饰不能绕过导出检查；论文事实文字保持可编辑，原始图表保持独立图片对象。

## 推荐检查

1. `render_html_slide` 检查实际 HTML 和资源。
2. `inspect_html_layout` 读取程序问题；需要时用 `review_slide` 检查视觉与事实。
3. 修改后保存新的 binding，并重新检查新版本。
4. 导出后读取对象映射和 unsupported features。
5. `render_pptx` 后用 `validate_export` 对照实际 PowerPoint 渲染和 OOXML 对象。

以上是参考处理关系，不是主 Agent 必须逐项执行的固定脚本。局部预览或阶段性草稿可以在满足当前请求后
停止，并明确尚未执行的交付检查。
